## 📖 Project Overview

Flooding is one of the most significant natural hazards affecting South India. This project applies GIS techniques to analyze flood susceptibility by integrating multiple spatial datasets, including elevation, slope, river proximity, and rainfall.

The analysis was carried out entirely in **QGIS**, resulting in a flood susceptibility map that classifies the study area into **Low**, **Medium**, and **High Risk** zones. The workflow and project presentation are included in this repository.

## 🔄 Methodology

The project followed these major steps:

1. Prepare the study area boundary.
2. Process the SRTM DEM.
3. Generate elevation and slope layers.
4. Extract and buffer river networks.
5. Integrate rainfall data.
6. Reclassify raster datasets.
7. Perform weighted overlay analysis.
8. Generate the final flood susceptibility map.
